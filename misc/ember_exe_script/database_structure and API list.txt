3. Make Sync run the pipeline properly

Use a Cloud Run Job for the pipeline:

POST /api/sync creates a Run entity with status queued, starts the job with CHILD_ID and RUN_ID, and returns immediately.
The job reads the likes, then runs the three stages. After each stage it updates the Run entity (step, progress, error).
The dashboard keeps polling /api/status, which now reads the Run entity. Any instance can answer it.
When the run finishes, /api/report reads VideoAnalysis, Themes and Quest.
