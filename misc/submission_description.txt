Ember helps parents know what their child actually watches on YouTube without rewatching it. Parents tend to see only titles and thumbnails, and titles mislead: a "toy review" can be a sales pitch, and a "game" video can be a masterclass in careful craft. Ember reads the videos a child has liked, has Gemini watch each one, and turns the result into a short report a parent can read in a minute.How it works: after a one-time consent, the app pulls the child's liked videos through the YouTube Data API (or the parent pastes a few links). A three-stage Gemini pipeline then runs. Stage one has Gemini analyse each video itself and return schema-constrained JSON: a plain-language summary of what happens, what holds the child's attention, how much real learning it contains, whether it leans on buying pressure or chance-based rewards, and questions a parent could ask. The child's age calibrates the safety judgement. Stage two groups the videos into interest themes. Stage three writes one printable weekend activity built from those themes, so insight turns into something the family can do together. 
The parent dashboard is a mobile, Family Link-style page with an Ember tab split into six sections: Overview (summary and videos worth a look), Weekend quest, Interests (a theme graph), Behind the title (what the title says versus what actually holds attention), Watch mix (subjects and learning value) and Videos (every video, filterable).
Google Cloud: Gemini is the core of the product. It does the video understanding, the structured reasoning for safety and learning value, the theme clustering and the activity planning. Cloud Run hosts the FastAPI backend and the static frontend as a single container deployed straight from source, with CPU kept allocated so the analysis can run in the background. Secret Manager supplies the Gemini key and the OAuth client to Cloud Run, so no credentials live in the code. Firestore stores each child's reports, themes and quest so they persist across Cloud Run instances, and Firebase Authentication signs the parent in. 


Limits we are upfront about: the YouTube API does not expose watch history, so Ember reports on liked videos, and supervised Family Link accounts are blocked by the API, so the child's account must be a standard one.
